# Biobella Scroll Story

Use os padrões descrito no PDF e as imagens para criar uma landing page com movimento pelo scroll usando as imagens da doutora. A clinica dela se chama BioBella e sua paleta e predominantemente Branco com detalhes vinho e dourado.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://biobella-scroll-story.lovable.app
